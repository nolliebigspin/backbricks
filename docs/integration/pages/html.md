---
title: HTML quickstart
description: Connect a plain HTML site with Backbricks.
---

Copy the form snippet from your Backbricks dashboard. Its action needs the deployment URL, actual form key and project publishable credential.

For a JavaScript-free form, select the dashboard's HTML form settings and enable the honeypot. For private attachments, use the SDK to upload the file, wait for the ready result, then include its reference when submitting the form.
