# Changesets

Release notes for the Backbricks product. The product version is the version of `@backbricks/server` (the image `ghcr.io/nolliebigspin/backbricks`); other workspace packages stay private until they are published (the SDK and CLI with M5).

- Describe a user-visible change: `bunx changeset` and pick `@backbricks/server` (patch, minor or major), or add a Markdown file here by hand.
- Release: see "Releasing" in [CONTRIBUTING.md](../CONTRIBUTING.md).
